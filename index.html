CVision – AI-Powered Resume Assistant & Recruitment Platform

"Turn your resume into a job-winning strategy."

CVision is an AI-powered recruitment platform designed to help candidates build, analyze, and improve their resumes while helping recruiters streamline candidate evaluation and recruitment workflows.

FastAPI PostgreSQL Google Gemini API React React Native Expo Supabase RESTful APIs JWT & OAuth 2.0 Pytest
GitHub Repository Live Demo

● The Problem

Job seekers often struggle with passing automated Applicant Tracking Systems (ATS) and lack transparent insight into their skill deficiencies compared to target role descriptions.

Concurrently, recruiters face high overhead manually sorting through unstandardized resumes, leading to inefficient candidate evaluation and prolonged hiring cycles.

● The Solution

CVision provides an end-to-end ecosystem combining intelligent resume creation, automated AI analysis, personalized career roadmaps, and recruiter evaluation tools into a single platform.

Candidates receive actionable ATS scores and tailored skill gap roadmaps, while recruiters access a centralized workflow to evaluate matching applicants with role-based access.
